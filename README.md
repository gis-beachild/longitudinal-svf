# SVF-based longitudinal (and pairwise) registration method

 # Installation
To install the necessary dependencies, please follow these steps:
1. Clone the repository:`
2. Configure the data configuration file in the `data/` directory to point to your dataset and its relative information.
3. Launch the experimentation (training/predict part) using :
```bash launch_experimentation.sh -d DATASET ...```
4. Compute the metrics from the results folder using:
```bash result.sh -d DATASET ```
